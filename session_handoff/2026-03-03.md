## Key Architecture Notes
- **install.sh** does NOT install the GUI. The GUI is a standalone AppImage built independently via `build_gui.sh`. This is intentional.
- The daemon binary is at `target/release/kprotect` and installed as `kprotect-daemon`.
- The PAM module `libkprotect_pam.so` gets installed to `/lib/x86_64-linux-gnu/security/pam_kprotect.so`.
- CI uses `tauri-apps/tauri-action@v0` which handles the Tauri build + GitHub release upload.
